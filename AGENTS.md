# CultureQui Studio

Projet indépendant de cultureQui. Node 24, aucune dépendance npm de production.
Ne jamais ajouter des médias ou des secrets au Git. Données dans DATA_DIR uniquement.
Une programmation locale n'est pas une confirmation de réception par un réseau.
Supprimer le MP4 seulement quand TOUTES les destinations sont delivered.
Ne pas relancer automatiquement une publication dont le résultat est ambigu : risque de doublon.
TikTok est une destination manuelle explicite, pas une intégration Direct Post privée.
Exécuter npm run check et npm test après toute modification du moteur.
Ne pas publier ni déployer sans configuration de l'hébergement et des comptes.
